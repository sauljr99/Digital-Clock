Digital Clock

A simple digital clock I made that shows the current time in
a GUI window and updates every second. It displays hours,
minutes, and seconds with AM/PM format.

Language: Python
Libraries: Tkinter and ttk (for the window and label),
           time / strftime (to grab and format the current time)

Notes:
- Run the .py file and a small clock window will pop up.
- The font used is ds-digital which gives it that classic
  digital clock look. If that font is not installed on your
  computer it may show up in a default font instead.
